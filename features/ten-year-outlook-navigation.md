# Ten-year outlook navigation

## Scope and status

Task 1 of the [ten-year flood-risk outlook plan](ten-year-flood-risk-outlook.md) is complete. The user explicitly approved this task with "yes do it". The implementation record below describes its initial release.

Subsequent status: the dataset audit is complete. The user then explicitly requested a hypothetical maps/charts/method preview in this same sub-tab. The initial unavailable-projection introduction described below has been replaced by that [hypothetical preview](ten-year-hypothetical-maps-and-charts.md); real projection-model work remains pending.

## Strategy

Predictive Risk Views now contains two sub-tabs: **Near-Term Screening** and **10-Year Outlook**. The existing near-term view is selected by default. Its five screening cards, graph selections, and input dialog retain their existing behavior.

The outlook uses a separate introductory component. It contains a planning label, a statement that projections are not yet available, and descriptions of the planned map comparison, scenario chart, and method panel. These descriptions are previews rather than calculated results. Dataset preparation, projection methods, selectors, maps, and charts remain later approved tasks.

This navigation follows the international research's distinction between operational screening and future planning. No outlook dataset, probability, scenario result, API request, alert, or incident is generated by this component.

## Implementation

- `frontend/src/components/FloodRiskMultiView.tsx`: owns the selected sub-tab and accessible tab controls. Both panels stay mounted, preserving near-term graph selections during switching. Changing tabs closes the near-term input dialog.
- `frontend/src/components/TenYearRiskOutlook.tsx`: owns the planning introduction and pending-data state.
- `frontend/src/ten-year-risk-outlook.css`: styles only the new tab controls and outlook. Uses the dashboard's existing dark colors and typography.

Tab controls use linked tab/panel IDs, selected state, and roving keyboard focus. Left/right arrows cycle between tabs; Home and End select the first and last tab. Hidden panels are excluded from the active view and keyboard navigation.
